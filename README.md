# DevLinks - Denival28

> 🔗 Agregador de links minimalista com dark mode e tema roxo

## 🎨 Sobre

DevLinks é um projeto do curso **Discover** da RocketSeat. Uma página minimalista para agregar seus links principais em um único lugar, com tema roxo customizado e funcionalidade de dark mode.

## ✨ Funcionalidades

- 🌙 Dark Mode / Light Mode
- 📱 Design responsivo
- 💜 Tema roxo elegante
- ✨ Animações suaves
- 🔗 Links customizáveis
- 💾 Tema salvo no localStorage

## 🚀 Como usar

### 1. Clonar o repositório
```bash
git clone https://github.com/denival28/devlinks.git
cd devlinks
```

### 2. Abrir no navegador
Abra o arquivo `index.html` diretamente no navegador ou use uma extensão como Live Server no VSCode.
